📄 قوانین و شرایط استفاده

۱. قوانین عمومی

استفاده از سایت و خدمات GAME TROLL به معنی مطالعه و پذیرش قوانین و شرایط استفاده است.

۲. حساب کاربری

اطلاعات ثبت‌نام باید صحیح باشد و مسئولیت حفظ رمز عبور و امنیت حساب بر عهده کاربر است. استفاده از حساب دیگران یا دسترسی غیرمجاز مجاز نیست.

۳. سفارش و خرید پک

ثبت سفارش به معنی درخواست خرید پک انتخاب‌شده است. کاربر باید مشخصات سفارش و مبلغ را پیش از تأیید بررسی کند.

۴. پرداخت

پرداخت باید از روش رسمی اعلام‌شده انجام شود. اطلاعات حساس بانکی یا رمزها را برای اشخاص دیگر ارسال نکنید. تأیید سفارش پس از بررسی پرداخت انجام می‌شود.

۵. دریافت پک

پس از تأیید پرداخت، گزینه دریافت پک فعال می‌شود و فرآیند ارسال از طریق ارتباط با مدیریت GAME TROLL در تلگرام انجام خواهد شد.

۶. بازی‌ها و محتوا

بازی‌ها، اخبار، آموزش‌ها و سایر محتوا طبق اطلاعات موجود در سایت ارائه می‌شوند. مسئولیت استفاده از محتوا مطابق قوانین محل زندگی کاربر بر عهده خود اوست.

۷. امتیازدهی و نظرات

نظرات باید محترمانه و مرتبط باشند. محتوای توهین‌آمیز، اسپم، تبلیغات نامرتبط یا محتوای خلاف قوانین قابل حذف یا رد شدن است.

۸. پشتیبانی

برای مشکلات سفارش، پرداخت، دریافت پک یا حساب کاربری از بخش پشتیبانی و تیکت استفاده کنید و در صورت نیاز شماره سفارش را درج کنید.

۹. لغو سفارش و بازگشت وجه

شرایط لغو سفارش یا بازگشت وجه با توجه به وضعیت سفارش و نوع محصول بررسی می‌شود و درخواست باید از طریق پشتیبانی ثبت شود.

۱۰. امنیت حساب

رمز عبور را در اختیار دیگران قرار ندهید. تلاش برای نفوذ، دسترسی غیرمجاز یا دور زدن محدودیت‌های امنیتی ممنوع است.

۱۱. فعالیت‌های ممنوع

هرگونه هک، خرابکاری، ارسال درخواست مخرب، سوءاستفاده از باگ، دسترسی به اطلاعات دیگر کاربران یا ایجاد اختلال در سرویس ممنوع است.

۱۲. حریم خصوصی

اطلاعات حساب و فعالیت‌های لازم برای ارائه خدمات، احراز هویت، سفارش، پشتیبانی و امکانات مرتبط با حساب استفاده می‌شود.

۱۳. تغییر قوانین

GAME TROLL می‌تواند در صورت نیاز قوانین را به‌روزرسانی کند. نسخه جدید پس از انتشار در سایت ملاک استفاده خواهد بود.

۱۴. مالکیت محتوا

نام، لوگو، طراحی اختصاصی، نوشته‌ها، تصاویر و سایر محتوای اختصاصی GAME TROLL متعلق به GAME TROLL است و کپی یا بازنشر بدون اجازه مجاز نیست.

۱۵. ارتباط با مدیریت

برای پیگیری سفارش، دریافت پک یا سایر موارد می‌توانید از پشتیبانی سایت یا مدیریت تلگرام استفاده کنید: @GameTrollAdmin

این متن شرایط استفاده عمومی سایت است و جایگزین مشاوره حقوقی تخصصی در حوزه قضایی محل فعالیت سایت یا کاربر نیست.

🔒 حریم خصوصی

اطلاعاتی که دریافت می‌شود

اطلاعات حساب مانند نام کاربری، ایمیل، اطلاعات سفارش، تیکت‌های پشتیبانی، امتیازها و نظرات برای ارائه قابلیت‌های سایت استفاده می‌شوند.

نحوه استفاده

این اطلاعات برای ورود و احراز هویت، مدیریت سفارش‌ها، پشتیبانی، اعلان‌ها، علاقه‌مندی‌ها و قابلیت‌های مرتبط با حساب استفاده می‌شود.

امنیت

رمز عبور نباید در رابط کاربری به‌صورت خام ذخیره شود و احراز هویت از طریق API و نشست کاربری انجام می‌شود.

حساب کاربری

کاربر می‌تواند اطلاعات پروفایل خود را مدیریت کند و در صورت نیاز درخواست حذف حساب خود را از داخل سایت ثبت کند.

تماس

برای پرسش‌های مرتبط با حریم خصوصی می‌توانید از بخش پشتیبانی سایت یا مدیریت GAME TROLL در تلگرام استفاده کنید.
